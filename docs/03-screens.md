Бухгалтер видит только экран 11 и только открытые месяцы. В меню у него нет ничего другого.
Прямой переход на чужой адрес даёт страницу «Нет доступа», а API отвечает 403.

На телефоне: боковое меню прячется в кнопку, KPI идут по два в ряд, водопад горизонтальный, в таблицах остаются
ключевые столбцы, остальное открывается по тапу на строку.
