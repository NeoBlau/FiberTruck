# Обновление FiberTruck: полный парк и резервное копирование

Обновляется существующая установка. Новых миграций и изменений схемы базы нет.
Скрипт не запускает импорт истории, заполнение демо или сброс пользователей.

Из папки установленной программы:

```bash
git pull --ff-only && sudo bash deploy/update.sh
```

Если программа установлена по пути из README:

```bash
cd /opt/fibertrack && git pull --ff-only && sudo bash deploy/update.sh
```

Используйте существующую папку и её `.env`, чтобы Docker Compose сохранил имя проекта
и существующие тома. Не разворачивайте обновление в другой папке как новую установку.
Рабочую базу не нужно повторно заполнять или импортировать Excel для обновления кода.

Перед пересборкой скрипт сохраняет в `backups/before-update-ДАТА-ID/`:

- `database.sql.gz`: вся текущая база;
- `uploads.tar.gz`: оригиналы загруженных файлов;
- `server.env`: существующий `.env`, с правами 600.

При ошибке резервного копирования пересборка не начинается. Затем собирается и
перезапускается только `backend` с `--no-deps`. База и её том не пересоздаются.
Предусмотрено краткое прерывание работы приложения при перезапуске. Стандартные
миграции Alembic запускаются как прежде; новых миграций в этом обновлении нет.

После обновления откройте прежний серверный адрес, выберите нужный месяц и нажмите
«Обновить данные». Просмотровые экраны также сверяются с сервером раз в минуту и
при возврате на вкладку. Во время редактирования формы фоновая перерисовка отключена.

## Полный резервный архив с сайта

Владелец → Настройки → Полное резервное копирование → Скачать полный резервный архив ZIP.
Руководитель и бухгалтер доступа к этому архиву не имеют.

В архиве: вся база SQL, пользователи и их хэши паролей, настройки, журнал,
история загрузок, исходные файлы Excel, код backend/frontend/deploy, compose,
образец `.env`, `manifest.json` с SHA-256 и `RESTORE.txt`.
Рабочий `.env`, сертификаты и настройки операционной системы нужно хранить отдельно.
При обновлении `.env` сохраняется автоматически в локальной копии перед обновлением.

Для восстановления используйте инструкцию `RESTORE.txt` из конкретного архива:
восстановление выполняется в отдельную пустую базу, с остановленным backend.
Расположение тома uploads должно совпадать с `upload_directory` из manifest,
либо нужно исправить пути `uploads.path` на новое расположение тех же файлов.

## Что изменилось

Дашборд содержит полный рейтинг дополнительно к топ-5. В «Машинах» видны доходы,
расходы, пробег и рабочие дни. В подробной таблице и карточке доступны все статьи,
НДС и документы. Отчёт руководителю включает все машины и все статьи,
печатается на нескольких страницах без обрезания. Excel содержит месячную детализацию,
общие расходы и годовую сводку; суммы сохраняют копейки.

Рабочие дни из шаблона используются и без графика диспетчера. Незаполненная
амортизация отличается от нулевой, показывается предупреждение. Владелец может
явно загрузить отсутствующую амортизацию из таблицы прибыли через предпросмотр;
существующие суммы и вручную изменённые машины не перезаписываются. При одном лишь
обновлении кода никакие значения амортизации не меняются.

## Если на другом компьютере нет сентября

На присланных фотографиях есть и локальные HTML-файлы `C:/Users/...`, и серверная
страница. Локальный файл не является общей серверной базой. Всем нужно открывать
один и тот же адрес установленного сервера. Выбор месяца теперь доступен списком;
экран отчёта не подменяет пустой выбранный месяц другим месяцем.

Обновление сохраняет то, что уже находится в рабочей базе. Данные из других
локальных файлов сами в неё не переносятся. Если после обновления и обновления
данных сентября действительно нет в серверной базе, нужны заполненный оригинал
или резервная копия той установки, где он присутствует. Присланный файл за сентябрь
содержит 58 машин, но числовые поля пробегов, дней, доходов и расходов в нём пустые.

## Добавить прошлый месяц через сайт

Владелец → **Месяцы → Добавить месяц**. Выберите месяц и год и нажмите
**«+ Добавить месяц»**. Новый месяц откроется для ввода, в том числе если он раньше
самого первого месяца в таблице. После этого он доступен в «Загрузка и ввод»
и в выборе месяца на дашборде. Существующие показатели других месяцев не меняются.
Повторное добавление уже существующего месяца не создаёт дубликат и не переоткрывает
закрытый месяц. Для закрытого месяца используйте «Переоткрыть» с причиной.

## Шаблон топлива в литрах

Владелец: **Топливо → выберите месяц → Скачать шаблон топлива**.
Владелец и бухгалтер также могут скачать его из **Загрузка и ввод** за выбранный месяц.
В Excel две колонки: **Автомобиль** и **Количество литров за месяц**. Каждая машина
указана один раз. Заполняется только общее количество литров за выбранный месяц,
без дат, РН, Е100 и ГЛОНАСС. Рубли и цена за литр сюда не вносятся.
Допускаются неотрицательные значения с точностью до 0,001 л.

Загрузите заполненный файл через «Загрузка и ввод», проверьте предпросмотр и
нажмите «Применить». Месяц должен быть открыт. Пустая ячейка оставляет прежние данные
автомобиля; 0 явно задаёт нулевой итог. Заполненная строка заменяет все прежние
топливные записи этой машины за этот месяц, включая разбивку по дням. Другие машины,
месяцы и финансовые суммы сохраняются. Итоги отображаются как месячные литры,
без проверки по суточным порогам и без отнесения к отдельной топливной карте.
Владелец может откатить загрузку в истории. Старые форматы заправок продолжают
поддерживаться. Само обновление программы не преобразует и не меняет ранее введённые данные.

## Горизонтальная прокрутка длинных таблиц

Если нижняя полоса широкой таблицы находится за пределами окна, внизу окна
появляется закреплённая панель «Таблица ↔»: полоса прокрутки и стрелки влево/вправо.
Она синхронизирована с таблицей и не требует прокручивать страницу до последней
машины. Когда обычная нижняя полоса видна, закреплённая панель скрывается.
Также доступно **Shift + колёсико мыши** над таблицей. Обычное колёсико продолжает
прокручивать страницу вертикально. При печати панель не выводится.

## Изменение парка и состав шаблонов

Финансовый шаблон, топливный шаблон и список машин на экране ввода получают
единый состав выбранного месяца с сервера. Машины, добавленные импортом, учитываются
наравне с добавленными вручную; наличие машины в последнем графике больше не является
условием включения в шаблон.

- «В парке с» — первый день работы, включительно.
- «Выведена с» — первый день, когда машина уже не работает.
- Если машина работала хотя бы один день месяца, она включается в этот месяц.
  Например, ввод 15 сентября и вывод с 1 ноября: есть в сентябре и октябре,
  нет в августе и ноябре. Текущая неактивность не убирает её из этих прошлых месяцев.
- Для машины без дат активность используется как запасное правило. Неактивная
  машина без даты вывода включается только в месяцы, где есть её реальные записи:
  график, пробег/дни, финансовые операции или топливо. Даты не угадываются.

Для точного состава прошлых месяцев заполните даты в справочнике. Уже записанные
показатели и прежние файлы при обновлении программы не преобразуются. После изменения
парка скачайте шаблон заново: ранее скачанный Excel самостоятельно не обновляется.

## Изменить короткий номер машины

Владелец или бухгалтер: **Справочник машин → машина → Короткий номер → Сохранить**.
Номер проверяется на формат и занятость (ведущие нули и пробел перед буквой
нормализуются). Госномер, даты работы, амортизация и постоянный внутренний ID
сохраняются. История пробега, дней, доходов, расходов, графиков и топлива остаётся
у той же машины. В журнале записываются старый и новый короткие номера.

После переименования скачайте свежие шаблоны. Применённые загрузки и их история
сохраняются; ожидающие применения предпросмотры, затрагивающие старый или новый
номер, отменяются с объяснением — файл нужно загрузить повторно. При откате загрузки
вручную переименованная машина не удаляется из справочника.

## Топливо: расход за месяц, графики и сигналы

Раздел **«Топливо» → выберите месяц** показывает крупную сводку в л/100 км,
объём литров, расходы в рублях с НДС, графики по автомобилям и динамику до 12 месяцев.
Полный список машин находится ниже графиков. Есть фильтр «Только требующие проверки»
и переход из строки в карточку автомобиля. Прежняя сверка РН/Е100/ГЛОНАСС доступна
в раскрывающемся блоке, если такие данные имеются.

Литры берутся из топливного шаблона. Пробег и суммы расходов на топливо — из
финансового шаблона **за тот же месяц**. Показатель рассчитывается как
`литры / километры × 100`; это отношение внесённых месячных литров к пробегу.
Общий показатель парка — сумма литров сопоставимых машин, делённая на сумму
их пробега, а не простое среднее индивидуальных расходов. Указывается количество
машин с достаточными данными. Отсутствующие значения не подменяются нулями.

Сигналы: выше/ниже порога л/100 км; рост л/100 км к предыдущему календарному месяцу;
литры при нулевом/отсутствующем пробеге; пробег при нулевых/отсутствующих литрах.
Большой объём сам по себе не помечается как перерасход: сравнение учитывает пробег.
При пропуске предыдущего месяца процент роста не вычисляется.

Пороги меняет владелец в «Настройки → Топливо». По умолчанию: 20–45 л/100 км,
рост больше 20%. «Сверх порога, л» = литры − пробег × верхний порог / 100
(если результат положительный). Это ориентир для проверки внесённых данных,
не подтверждение потерь или нарушения: нужно сверять полноту месяца, документы
и условия работы. Статистика доступна владельцу и руководителю; бухгалтеру
финансовые агрегаты не передаются. Данные при обновлении не пересчитываются в базе:
аналитика строится по существующим записям.
