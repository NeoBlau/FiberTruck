# Проверенный приватный пакет Excel

Пакет загружается только по явному запросу владельца. Обычное обновление программы
само по себе не импортирует и не заменяет финансовые данные.

Пакет `backend/app/packages/reviewed-input.ftpack` зашифрован и аутентифицирован
Fernet. Исходные Excel, манифест с контрольными суммами и финансовые значения не
публикуются открыто. Ключ передаётся владельцу отдельно, не хранится в Git и образе.
Не помещайте ключ в `.env`, код, аргументы команд или публичный репозиторий.

## Обновление и однократное применение

После получения правильного ключа и проверки состава пакета:

```bash
cd /opt/fibertrack
git pull --ff-only origin claude/stage-2-design
FT_NO_PULL=1 FT_IMPORT_REVIEWED_BUNDLE=1 bash deploy/update.sh
```

Скрипт сначала сохраняет базу, загруженные файлы и `.env`, обновляет программу и
проверяет её запуск, затем просит ключ (ввод не отображается). Ключ передаётся
контейнеру через stdin, не через аргументы или журналы. Для автоматического запуска
можно задать `FT_BUNDLE_KEY_FILE` на файл с правами 600 вне репозитория.

Импорт — авторитетный снимок только перечисленных в пакете машин, месяцев и
присутствующих общих строк. Он заменяет их финансовые операции (включая старые
исторические итоги), пробеги, рабочие дни и месячное топливо. Пустые значения в
снимке удаляют старые показатели, а не сохраняют ошибочные остатки. Числовой ноль
остаётся явно внесённым нулём. Неперечисленные машины, другие месяцы, справочные
настройки, пользователи, пароли и график выпуска сохраняются. Новые машины из
финансового файла добавляются как при обычной загрузке; даты службы не выводятся
из присутствия в файле. Для явно подтверждённых старых обозначений пакет может
очистить показатели только указанного месяца без удаления автомобиля из справочника.

Все файлы проверяются и применяются в одной транзакции. Ошибка последнего файла
отменяет весь импорт, новые файлы этой попытки удаляются. На время операции
запись в затрагиваемые таблицы сериализуется; обычное чтение базы остаётся доступным.
Статусы и даты изменения уже существующих закрытых месяцев после операции
восстанавливаются. Выполнение требует существующего активного владельца; новый
пользователь или пароль для этого не создаётся.

Загрузки пакета видны в обычной истории с исходными снимками для отката. Повторное
обновление с тем же пакетом не дублирует данные и не перезаписывает последующий
ручной ввод. Частично или полностью откаченный пакет не применяется снова
автоматически.

## Проверка без сохранения и откат

Определите ту же команду Compose, что используется в `deploy/update.sh`: для
установки за nginx нужны оба `-f`. Команда внутри контейнера:

```bash
python -m app.cli reviewed-package --key-stdin
python -m app.cli reviewed-package --key-stdin --rollback
```

В stdin передаётся одна строка ключа; `--package` позволяет выбрать другой файл.
Без `--apply` проверка выполняется с последующим откатом транзакции. Откат всего
пакета идёт в обратном порядке и сохраняет текущие статусы месяцев. Он не обходит
штатные проверки более поздних загрузок и последующего ручного изменения данных.
Перед откатом также рекомендуется сделать полную резервную копию базы.

## Точечные исправления топлива

Пакет может содержать только месячный топливный файл без финансового файла за тот
же месяц. В таком случае машины сопоставляются с существующим справочником;
неизвестная машина останавливает весь импорт. Заменяются только литры машин,
перечисленных в топливном файле. Финансы, пробеги и топливо остальных машин
сохраняются. При наличии финансового файла сопоставление выполняется по его
проверенному списку, как и для полного пакета.

Аналогично допускается отдельный финансовый файл с выбранными автомобилями,
без топливного файла. Он заменяет их финансовые показатели и пробег за указанный
месяц, сохраняя топливо, общие статьи вне файла и показатели других машин.
